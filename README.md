# LAN Chat Overlay

צ'אט טקסט שקוף בין שני מחשבים באותה רשת מקומית (LAN), מיועד לשבת מעל משחק כ-overlay. אין שרת חיצוני — חיבור ישיר (TCP) בין המחשבים.

## איך זה עובד

- שני הצדדים מריצים בדיוק את אותה תוכנה.
- כל צד מזין את כתובת ה-IP (ברשת המקומית) של הצד השני ולוחץ **התחבר**.
- מי שלוחץ ראשון הופך אוטומטית ל"מארח" (פותח פורט האזנה 51837), והשני מתחבר אליו כ"לקוח". אין צורך להחליט מראש מי מארח.
- החלון קטן, בפינה, שקוף. **כשאין הודעות לזמן מה הוא נעשה שקוף לגמרי** (רק נקודה קטנה נשארת בפינה כתזכורת). ברגע שמגיעה או נשלחת הודעה הוא דועך פנימה לכמה שניות ואז נעלם שוב.
- כברירת מחדל החלון "קליק-ת'רו" — לא חוסם קליקים למשחק. לחיצה על סמל הנעילה (📌) בפינה, או `Ctrl+Shift+C`, נועלת אותו במצב פעיל כדי להקליד בנוחות.

## התקנה (על כל אחד משני המחשבים)

דרוש [Node.js](https://nodejs.org) מותקן.

```bash
cd lan-chat-overlay
npm install
npm start
```

## שימוש

1. ודאו ששני המחשבים באותה רשת (Wi-Fi/LAN ביתי).
2. בכל מחשב, מצאו את כתובת ה-IP המקומית שלו (Windows: `ipconfig`, בשורת "IPv4 Address").
3. במחשב א' הזינו את ה-IP של מחשב ב', ולהפך.
4. לחצו "התחבר" משני הצדדים (אין חשיבות לסדר).
5. ברגע שהחיבור נוצר, אפשר לצ'וטט. החלון נשאר צף מעל המשחק.

## הערות חשובות

- **פורט**: התוכנה משתמשת בפורט קבוע `51837`. אם יש פיירוול (Windows Defender וכו') ייתכן שיהיה צורך לאשר גישה לתוכנה בפעם הראשונה.
- **רשת מקומית בלבד**: זה עובד רק כששני המחשבים על אותה רשת (לא דרך האינטרנט הפתוח). לחיבור מרחוק יידרש פתרון אחר (relay/שרת מתווך).
- **בניית קובץ הפעלה (exe)**: כרגע מריצים עם `npm start`. אם תרצו קובץ `.exe` עצמאי בלי צורך ב-Node מותקן, אפשר להוסיף את `electron-builder` — תגידו לי ואבנה את זה.

## מבנה הקבצים

- `main.js` — תהליך הרקע: יצירת החלון השקוף, כל לוגיקת ה-TCP (שרת/לקוח אוטומטי).
- `preload.js` — גשר בטוח בין החלון לתהליך הרקע.
- `index.html` — כל ממשק הצ'אט, כולל אנימציית השקיפות.
